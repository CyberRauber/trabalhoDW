# Meu Universo Gamer

### 1. Sobre o trabalho

Neste trabalho eu fiz um site sobre jogos que eu gosto.
Escolhi esse tema porque é algo que eu gosto e achei mais fácil fazer um site sobre um assunto que eu conheço.

### 2. Como fiz

Primeiro fiz a estrutura do site usando HTML.
Depois fiz o CSS para mudar as cores, tamanhos, espaços e organizar os elementos da página.
Por último, coloquei os arquivos no GitHub e publiquei o site usando o GitHub Pages.

### 3. Ferramentas usadas

As ferramentas que eu usei foram:

- Visual Studio Code
- HTML
- CSS
- GitHub
- GitHub Pages

### 4. O que aprendi

Com esse trabalho eu aprendi melhor como organizar uma página usando HTML e como usar CSS para deixar o site com uma aparência melhor.
Alguns comandos de Css novos, como ">", ":first-child".

### 5. Dificuldades

Tive algumas dificuldades para organizar os arquivos e deixar o site funcionando corretamente.
Também precisei testar algumas vezes para corrigir detalhes do HTML e do CSS.

### 6. Conclusão
No final consegui fazer e publicar meu próprio site usando HTML, CSS, Git e GitHub Pages.

# Universo Gamer

Este é um site sobre alguns jogos que eu gosto e que fazem parte do meu tempo livre.

# Sobre o projeto

O site foi criado como trabalho da disciplina de Desenvolvimento Web I.

O objetivo é apresentar alguns jogos que eu gosto, como:

- Rocket League
- Minecraft
- Clash Royale
- Xadrez

Também coloquei algumas coisas que eu considero importantes em um jogo, como progressão, exploração e estratégia.
